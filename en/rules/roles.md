# Roles

- **Strategist** — decides what to do and in what order; owns `STATE.md` priorities.
- **Builder** — makes things (code, pages, files); owns the deliverables assigned to it.
- **Watcher** — checks sources on a schedule; reports only what is new and verified; silent otherwise.
- **Editor** — verifies before anything goes out; reads the real thing, never a summary.

One agent can hold several roles, but never both Builder and Editor on the same deliverable.
